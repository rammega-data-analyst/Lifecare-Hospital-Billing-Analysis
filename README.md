# Lifecare Multispeciality Hospital – Patient Billing Analysis

## Project Overview
This Excel-based data analytics project focuses on analyzing hospital patient billing and treatment costs to understand patient distribution, treatment expenses, and billing performance.

## Project Objectives
- Analyze patient billing information.
- Evaluate treatment costs.
- Identify billing trends and patterns.
- Track key hospital performance indicators.
- Present insights through an interactive Excel dashboard.

## Data Cleaning
- Identified missing values.
- Reviewed data quality.
- Cleaned and prepared the dataset for analysis.
- Final dataset contains 500 patient records.
